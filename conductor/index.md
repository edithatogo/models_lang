# Local-model qualification programme

Active forward track: [Cross-platform model qualification, 8 November 2026](tracks/local-model-qualification_20261108/index.md).

This repository owns the **model candidate catalogue, task benchmark definitions, hardware/runtime qualification artefacts and evidence-based adaptation comparisons**. It does not own the operational records, decisions or deployment approval of downstream products.

Existing Intel/OpenVINO LoRA, mem0/LFM2-ColBERT and ONNX work remains intact. Do not duplicate retrieval or inference backends. Candidate metadata is not device support or fitness evidence.

The first reviewable slice is a source-verified catalogue plus a versioned result contract. Later implementation and physical hardware tests require separate evidence.
